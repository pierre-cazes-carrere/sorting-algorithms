
# Sorting Algorithms - Cyberpunk Edition

## Lancement
```bash
python main.py
```

## Arborescence
- `main.py` : point d'entrée du programme
- `interface/interface.py` : toute l'interface graphique CustomTkinter
- `sorting/sorting.py` : les classes de tri (POO)
- `assets/` : images et sons

- matplotlib
